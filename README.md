# 员工培训平台

面向门店和企业的员工培训 H5。包含员工学习端、管理后台及腾讯云 CloudBase 后端。

- 员工端提供课程、视频学习、PPT 逐页阅读、考试、积分和排行榜。
- 后台管理组织与员工名单、培训资料、题库、学习进度、案例审核和积分兑换。
- 企业品牌配置页提供 Logo 上传、色卡选择、双端预览和配置下载。

## 本地体验

安装 Node.js 22 或更新的 LTS 版本。

```sh
npm ci
npm run employee:dev
# 在另一个终端运行
npm run admin:dev
```

- [员工学习端](http://localhost:5174/employee/?demo=1)
- [管理后台](http://localhost:5173/admin/?demo=1)

演示员工为「预览员工」，组织为「示例门店」。演示课程含两页 PPT 和一段 12 秒视频。两个演示端的变化存储在各自浏览器站点内，跨端同步请使用配置好的 CloudBase 环境。

## 换企业品牌

1. 运行 `npm run brand:setup`，打开 [品牌配置页](http://127.0.0.1:5175/)。
2. 上传 PNG、JPEG 或 WebP Logo，选取企业色卡，企业名称可选填。
3. 导出配置包并解压到项目根目录。重启两端即可预览，正式环境需重新构建。

同一份 `config/brand.json` 用于员工端和管理后台。品牌配置页在本机浏览器处理上传图片。

## 正式部署

为每家企业配置独立的 CloudBase 环境、HTTPS 域名及员工登录方式。部署后可在后台导入员工名单和上传培训内容。详见[部署指南](docs/deployment.md)。

```sh
npm run verify
```
