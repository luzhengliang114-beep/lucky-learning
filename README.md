# 鹿lucky Learning

面向门店和企业的员工培训 H5。包含员工学习端、管理后台及腾讯云 CloudBase 后端。

鹿lucky 系列开源项目：展示名称采用「鹿lucky + 用途英文」，GitHub 仓库采用 `lucky-用途英文`。本项目用于学习培训，仓库名为 `lucky-learning`。

- 员工端提供课程、视频学习、PPT 逐页阅读、考试、积分和排行榜。
- 后台管理组织与员工名单、培训资料、题库、学习进度、案例审核和积分兑换。
- 企业换肤通过对话提供 Logo 或品牌色卡，配置后直接查看员工端和管理后台。

## 本地体验

安装 Node.js 22 或更新的 LTS 版本。

```sh
npm ci
npm run employee:dev
# 在另一个终端运行
npm run admin:dev
```

- [员工学习端](http://localhost:5174/employee/?demo=1)
- [管理后台](http://localhost:5173/admin/?demo=1)

演示员工为「预览员工」，组织为「示例门店」。演示课程含两页 PPT 和一段 12 秒视频。两个演示端的变化存储在各自浏览器站点内，跨端同步请使用配置好的 CloudBase 环境。

## 换企业品牌

在 Codex 或支持本地项目编辑的编程助手中打开项目后，助手会先提示：

> 请把企业 Logo 或品牌色卡发给我，我会配置到员工端和管理后台，再打开真实页面给你确认。

只有 Logo 时，可从 Logo 提取品牌主色；只有色卡时，可先应用颜色并保留默认 Logo。企业名称可一并提供。助手负责检查对比度、写入配置和验证两端展示，无需操作选色或导出页面。

后续需要决定的事项采用 A／B／C 选择题，每次一题并标明推荐项。涉及配色等视觉选择时，每个选项先展示真实员工端和后台的效果图，再让用户选择。选好后汇总方案，确认一次，再完成配置和真实页面验收。

同一份 `config/brand.json` 和 `brand/` 资源用于两端。开发者也可直接修改配置并运行 `npm run brand:validate`。详细流程见[企业品牌接入](docs/brand-customization.md)。

## 正式部署

为每家企业配置独立的 CloudBase 环境、HTTPS 域名及员工登录方式。部署后可在后台导入员工名单和上传培训内容。详见[部署指南](docs/deployment.md)。

```sh
npm run verify
```
