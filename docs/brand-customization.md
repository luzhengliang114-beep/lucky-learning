# 企业品牌接入

## 提供材料

在项目对话中发送企业 Logo 文件或品牌色卡即可。企业名称可以一并提供。助手首先提示：

> 请把企业 Logo 或品牌色卡发给我，我会配置到员工端和管理后台，再打开真实页面给你确认。

- 只有 Logo：从图中提取品牌色，背景保持中性，确保文字清晰。
- 只有色卡：先应用色卡，保留默认 Logo。
- 两者都有：按指定色卡及原始 Logo 配置。

预览截图中的 Logo 不能代替原始素材，不自动从截图裁切作为正式 Logo。

## 配置与验证

助手将 Logo 放在 `brand/`，统一更新 `config/brand.json` 的资源路径、颜色和企业名称。Logo 保持完整比例。换肤只调整品牌外观，保留已有业务功能。

主色用于操作按钮及选中状态；强调色用于辅助状态；底色优先选白色或接近白色的中性背景。正文与底色、按钮与文字均应具有足够对比度，不把所有页面区域铺成品牌色。

完成配置后运行：

```sh
npm run verify
```

在实际员工端和管理后台检查 Logo、页面标题、按钮、文字、表格和移动端排版，并打开两个页面供用户确认。无需模拟预览、配置包下载或手动解压。

本地开发预览地址：

- [员工端](http://localhost:5174/employee/?demo=1)
- [管理后台](http://localhost:5173/admin/?demo=1)

企业云资源、登录方式及培训内容初始化另按[部署指南](deployment.md)配置。
